# Beta Sender Lite

Beta Sender Lite by Beta Sender.

## Installation

### Windows
1. Download the latest **`.exe`** installer from the [Releases page](https://github.com/digi-bulk-marketing/68fcb009c94350869e4ff748/releases/latest).
2. Run the installer and follow the prompts.
3. Launch **Beta Sender Lite** from the Start menu.

## Updates

Download the newest installer from the [Releases page](https://github.com/digi-bulk-marketing/68fcb009c94350869e4ff748/releases/latest) and reinstall.
